◆ syncComponentVisibility()

void TreeModel::syncComponentVisibility ( Index component_id,
bool mesh_visible,
bool geometry_visible )

接收 GUI 管线回传的完整组件显隐结果（不是用户显隐命令）

参数
component_id组件 id；组件尚未入树时只保存，结构同步创建后应用
mesh_visible网格总开关
geometry_visible几何总开关
注解
这是显隐状态唯一写入点；对象树的用户入口只发请求。
