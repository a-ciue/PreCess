void QRenderWindow::hideSelectedFaces ( )

隐藏面选择器当前高亮选中的面（右键菜单"隐藏"）

仅面选择模式有效，其余模式为空操作；隐藏为渲染层单元过滤， 不修改模型数据，被隐藏面不渲染也不可拾取；安装结果时清空选择和高亮。

设置属性渲染方式

在控制台中调用示例： QModelManager.query.getComponentAttriInfo(0) App.registry.renderWindow.setAttriMode(0, "f_pressure_1", 1, {}) App.registry.renderWindow.setAttriMode(0, "f_color_3", 0, {}) App.registry.renderWindow.setAttriMode(0, "f_vectors_3", 3, {}) App.registry.renderWindow.setAttriMode(0, "v_vector_3", 3, { "glyph_scale": 0.5 }) App.registry.renderWindow.setAttriMode(0, "v_uv_2", 2, { "texture_path": "E:/MeshProjects/Project_Harmonic/data/texture_checker.bmp" }) App.registry.renderWindow.setAttriMode(0, "v_scalars_1", 1, {}) App.registry.renderWindow.setAttriMode(0, "v_scalars_1", 1, { "scalar_range": [2, 6] }) // blow.vtk 示例： App.registry.renderWindow.setAttriMode(0, "v_displacement9_3", 3, {}) App.registry.renderWindow.setAttriMode(0, "v_displacement9_3", 3, { "glyph_scale": 0.5 }) App.registry.renderWindow.setAttriMode(0, "v_thickness9_1", 1, {}) App.registry.renderWindow.setAttriMode(0, "v_thickness9_1", 1, { "scalar_range": [0, 2] })

参数
component_id目标 Component ID
attr_name属性名，前缀 v_/e_/f_/s_ 表示点/边/面/体，后缀 _3 表示属性分量为 3
mode渲染方式 0:RGB 1:SCALAR 2:UV 3:VECTOR
args其他参数（可选），如： "texture_path": 贴图路径（string） "glyph_scale": 箭头缩放比例（double） "scalar_range": 标量范围（长度为2的数组）
