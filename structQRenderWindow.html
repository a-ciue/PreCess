设置属性渲染方式

在控制台中调用示例： myItem.setAttriMode("face_pressure", 1, 2) myItem.setAttriMode("face_color_3", 0, 2) myItem.setAttriMode("face_vectors_3", 3, 2) myItem.setAttriMode("vertex_vector_3", 3, 0) myItem.setAttriMode("vertex_vector_3", 3, 0, "",0.5); myItem.setAttriMode("vertex_uv_2", 2, 0, "E:/MeshProjects/Project_Harmonic/data/texture_checker.bmp") myItem.setAttriMode("vertex_scalars", 1, 0) myItem.setAttriMode("vertex_scalars", 1, 0,"",-1,[2,6]) 对于blow.vtk: myItem.setAttriMode("displacement9_3", 3, 0) myItem.setAttriMode("displacement9_3", 3, 0,"",0.5) myItem.setAttriMode("thickness9", 1, 0) myItem.setAttriMode("thickness9", 1, 0,"",-1,[0,2])

参数
attr_name属性名
mode渲染方式 0:RGB 1:SCALAR 2:UV 3:VECTOR
type属性类型 0:VERTEX 1:EDGE 2:FACE 3:SOLID
texturePath贴图路径
glyphScale箭头缩放比例
scalarRange标量范围 (不给就是默认)
