class  IMeshIdQuery

详细描述

渲染层向模型层查询网格单元 id 的窄接口

vtkPart 保持不依赖 Qt/QML，模型层的 id 查询能力经本接口由桥接层（QRenderWindow）注入实现。 后续其他邻接类查询（面、体等）也在本接口上扩展。
