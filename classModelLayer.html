详细描述

负责管理多个 ModelData 实例的类

ModelLayer 允许动态添加、删除和查找模型，通过Observer模式发送模型事件。 使得 QML 层能够访问和控制网格数据。

按给定 id 把组件纳入指定模型（入全局池、登记 component_to_model_、gid 对账）

gid 对账顺序：几何索引 ensureIndexBuilt（快照克隆体索引未建，此处重建领新 gid）→ 点 gid 先 reclaimPointGlobalIds 按原值回收再 ensurePointGlobalIds 补缺 → 边 gid 先 reclaimEdgeGlobalIds 再 ensureEdgeGlobalIds 补缺；reclaim 与 ensure 幂等兼容， addModel（gid 尚未分配，reclaim 自然无操作）与快照恢复共用本路径。

异常
std::runtime_errormodel 不存在或 component id 已被占用，或 gid reclaim 冲突
