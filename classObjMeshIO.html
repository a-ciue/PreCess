◆ loadFromFile()

std::optional< ComponentDatas > ObjMeshIO::loadFromFile ( const std::filesystem::path & filename)
static

从文件加载 OBJ 模型，按 shape(group) 分组拆分为多个组件。

每个 shape 生成一个 ComponentData，其 MeshData 自包含： 只携带本组面实际引用的顶点（全局点索引重映射为组件内局部点索引）。

参数
filename要加载的文件的路径。
返回
加载的组件列表；文件解析失败时返回 std::nullopt。

◆ saveToFile() [1/3]

void ObjMeshIO::saveToFile ( const ComponentDatas & components,
std::ostream & os )
static

将组件列表保存到指定的输出流（如文件输出流）中。

每个组件写为一个 OBJ object（组件名作为 object 名）， 与 loadFromFile 按 shape 拆回组件对应；点索引按 OBJ 约定 1-based 且全文件连续，跨组件自动累加偏移。

参数
components要保存的组件列表（无网格的组件会被跳过）。
os用于写入数据的输出流。

◆ saveToFile() [2/3]

void ObjMeshIO::saveToFile ( const MeshData & mesh,
std::ostream & os )
static

将单个 MeshData 保存到指定的输出流（如文件输出流）中。

零拷贝写出全部点与面（点索引 1-based），不写 object 分组行； 适合 CTMesh 转换等只有单网格、无需组件语义的场合。

参数
mesh要保存的 MeshData 对象。
os用于写入数据的输出流。
