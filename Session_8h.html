详细描述

会话组合根：模型层、undo 栈、事件总线与四个系统的装配与有序拆解（不依赖 Qt）

Session 是原 app 层 QModelManager 装配逻辑的无 Qt 下沉：构造时按依赖序组装 ModelLayer / UndoStack / EventBus / ModelIO / Algo / Edit / Feature 系统， 并经内部转发观察者把模型层通知桥接为 ModelEvent（功能系统的 ModelEvent 订阅在无 Qt 宿主下照常工作）。Qt 侧适配器（QML 信号、参数回写桥）仍由 app 层 QModelManager 挂接。析构（或 teardown）按依赖逆序有序拆解。
